嵌套循环与平方增长 · 主题实验例子

探究问题

设输入规模 n，双层完整循环的操作数为 n²，记录 n 翻倍后次数增长为4倍。

相关数学关系

操作次数≈n²

原理

两层各执行 n 次的简单嵌套循环，操作次数随 n 平方增长。

可操作步骤

  1. 明确自变量、因变量及其单位，并写出初始条件。
  2. 改变一个变量，记录至少三组数值或观察数据。
  3. 用当前主题公式求出理论值，并与观察数据对照。
  4. 解释误差来源，判断模型是否适用于当前情境。

模型边界

并非所有两层循环都恰好 n²。
