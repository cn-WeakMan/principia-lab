# 总知识图谱

- 地址：`http://127.0.0.1:8000/graph/all`。后台 `/admin` 顶部也可打开。
- 直接使用只读 `GET /api/graph/all` 获取 SQLite 中的所有学段节点与关联（包括未发布草稿），需遵守原后台编辑器的访问校验；若配置 `PLAB_ADMIN_TOKEN`，页面填入令牌。
- 节点键值使用 `level:id` 避免学段间同 ID 冲突。
- 按学段、学科分列；同列节点按 sort_index 纵向排列；跨学段/跨学科连线显示。
- 支持学段与学科筛选、搜索、点击高亮及关联概念侧栏。页面仅查看，不修改数据库。
- 由于属于独立总图谱，原学段图谱与管理后台编辑功能不变。
