# 数据库管理页面

- 独立后台：`/database`，与用户页面分开。
- 历史地址 `/admin` 自动跳转到 `/database`，以避免旧书签失效。
- 新页面使用原有节点、跨学段关系、XLSX 和发布 API；无新数据库副本。
- 管理接口依赖 `X-Admin-Token`，局域网启动时请妥善保管启动时显示的令牌。
- 此版“独立页面”是逻辑与导航分离，并非独立端口或强制登录页。管理页面的 HTML 可以被访问，但管理数据 API 依然强制校验令牌。
- 普通客户页面去掉直接跳转管理后台的链接。

## 学习总结提示词

原有小学数学和初高中二级目录的生成按钮继续使用内置提示词模板；生成结果可编辑。局域网 HTTP 上浏览器可能限制自动复制，失败时请点击文本框并用 Command+C/Ctrl+C。
