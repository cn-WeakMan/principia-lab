# 全学段知识互通

- 首页提供 `/graph/all?embed=1` 总图谱预览与独立全屏入口。
- 数据库以 `(level,id)` 为联合身份，允许不同学段拥有相同 ID。
- 后台编辑已有节点 -> 选择跨学段关联 -> 多选并保存，使用现有 `/api/edges` 接口持久化，关系可反向查找。
- 普通「关联节点 ID」输入框仍只表示同学段关系，跨学段关系在独立窗口操作，以免覆盖其他边。
- `/knowledge/all?node=primary:example` 可定位指定节点。
- 原有学段内图谱仍采用其学段内容；跨学段浏览通过总图谱入口完成。
- 总图谱 API 受原编辑鉴权保护，启用令牌时首页 iframe 可能要求登录或在总图谱中输入令牌。
