# 总知识点页面

- 地址：`/knowledge/all`；旧总图谱 `/graph/all` 保留。
- 页面纵向划分：顶部项目名称和搜索栏约 10vh、中间数据库知识图谱 70vh、底部节点解释 20vh。
- 直接读取受管理员校验保护的 `GET /api/graph/all`，数据为 SQLite 未发布草稿节点和关联；包含说明、公式、适用范围、思考问题。
- 点击节点可显示解释并高亮关联；搜索/学段/学科筛选及刷新不修改数据库。
- 页面为只读；管理节点仍通过 `/admin`。若配置 `PLAB_ADMIN_TOKEN`，需要在页面输入令牌。
- 小屏设备沿用 10/70/20 垂直结构；详情区可内部滚动。
