# 局域网实验室与提示词修复

- 三个独立实验室页面现在复用完整学段页面脚本，加载节点、插件文件与统一页面渲染器。
- 本机 `http://127.0.0.1:8000/database` 的管理 API 不要求管理员令牌。
- 局域网其他设备默认仍需要管理员令牌；可信局域网中确实需要免令牌时，运行 `PLAB_UNSAFE_LAN_ADMIN=1 bash start.sh`。
- 免令牌意味着同一局域网内的设备能够修改或删除数据库内容。请勿向公网开放端口，也勿在不可信 Wi-Fi 开启。
- 普通客户端访问实验不需要管理员令牌。
- 更新后请强制刷新页面，避免浏览器使用旧 JavaScript 缓存。
